Wonders of Salalah

Where the Desert Turns Green 🌿

📖 About the Project

Wonders of Salalah is a PHP-based tourism website developed to showcase the attractions, history, culture, events, and natural beauty of Salalah, Oman.

The website provides visitors with organized tourism information through a simple and user-friendly interface.

🎯 Project Purpose

The purpose of this project is to create an informative tourism platform that allows users to explore Salalah and learn about its popular attractions, historical locations, cultural heritage, and events.

The project also demonstrates the use of PHP, MySQL, HTML, CSS, JavaScript, and XAMPP in developing a dynamic website.

✨ Main Features

* Tourism attractions and destinations
* History and cultural information
* Events and festivals
* Images and tourism content
* Salalah tourism video
* Contact form
* MySQL database integration
* Reusable header and footer components
* Responsive website design

🛠️ Technologies Used

* PHP – Backend and server-side functionality
* HTML5 – Website structure
* CSS3 – Styling and layout
* JavaScript – Interactive functionality
* MySQL – Database
* XAMPP – Local server environment
* phpMyAdmin – Database management
* Git & GitHub – Version control
* Git LFS – Large video file storage

🚀 How to Run the Project

1. Install XAMPP

Install XAMPP with Apache, PHP, and MySQL.

2. Place the Project

Copy the salalah project folder into the XAMPP htdocs directory.

macOS:

/Applications/XAMPP/xamppfiles/htdocs/

Windows:

C:\xampp\htdocs\

3. Start XAMPP

Open XAMPP and start:

* Apache
* MySQL

4. Set Up the Database

Open phpMyAdmin:

http://localhost/phpmyadmin/

Create the required database and import:

sql/db_setup.sql

Check the database connection settings in the files inside the php/ folder if necessary.

5. Open the Website

Once Apache and MySQL are running, open:

http://localhost/salalah/

Main pages include:

http://localhost/salalah/index.php
http://localhost/salalah/attractions.php
http://localhost/salalah/history.php
http://localhost/salalah/events.php
http://localhost/salalah/contact.php

📌 GitHub & Git LFS

The project is hosted on GitHub. The salalah.mp4 video is approximately 102 MB and is stored using Git LFS.

If cloning the repository, install Git LFS and run:

git lfs install

Then clone the repository normally.
